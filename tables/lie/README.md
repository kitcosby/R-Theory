# Lie tables — verified branching library

Representation-theory tables verified with the LiE workflow: every
entry was computed by two independent LiE builds (a 32-bit Windows
build and a native build) required to agree verbatim, with exact
dimension sums. PROVED grade throughout, except where a source is
stated otherwise in the file.

- `BRANCHING.md` — the banked tables: dimensions, tensor products,
  maximal-subgroup branchings, the E8 30380 census, the
  SO(10) → SU(5)×U(1) branchings with U(1) charges, and the
  2026-11-03 audit summary.
- `matrices/` — hand-built restriction matrices for embeddings the
  LiE INFO database does not carry (D5→A4, E6→D5T1, A4→A2A1T1),
  each with its construction and verification record.
- `AUDIT_REPORT_2026-11-03.md` — the branching-claim audit of the
  full R Theory record (database + manuscript): every claim
  checked, one notation inconsistency flagged (D1 chirality
  pairing, manuscript Vol III).

Algebra-first scope: these tables verify representation theory
only; they assign no physics labels.
